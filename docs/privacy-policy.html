Privacy Policy

Ezra-Zhao Channel Automation Tools · Effective date: October 17, 2026

1. Who operates these tools

These tools are personal automation scripts owned and operated by Guangyi Zhao, the owner of the YouTube channel “Ezra-Zhao” (@ezra-zhao). They are private, internal tools with no third-party users. Contact: ezra777.zhao@gmail.com.

2. What the tools do

The tools use the YouTube Data API v3, under the owner’s own OAuth 2.0 authorization, for three operations on the owner’s own channel only:

  • uploading the owner’s finished, self-produced original videos on a schedule (videos.insert);
  • attaching the matching cover image to each video (thumbnails.set);
  • filing each video into the owner’s own series playlists (playlistItems.insert), with occasional metadata updates to the owner’s own videos (videos.update).

All uploaded content is original and owned by the operator. The tools do not scrape data, do not operate any other channel, and are not offered to the public.

3. Data accessed

The tools access only the channel owner’s own channel data, and only to the extent needed for the operations above. The tools do not collect, store, process, or access any data about viewers, subscribers, commenters, or any other third party.

OAuth credentials are stored locally on the operator’s own computer and are used solely to perform the operations described in this policy.

4. No sharing, no sale of data

No data is sold, rented, shared, transferred, or disclosed to any third party, and no data is used for advertising or for any purpose other than managing the owner’s own channel as described above.

5. Revoking access

Access granted to these tools can be reviewed and revoked at any time through the Google Account permissions page: https://myaccount.google.com/permissions. Revoking access immediately stops the tools from making further API calls.

6. Compliance

Use of the YouTube API Services by these tools complies with the YouTube API Services Terms of Service. Google’s handling of data is described in the Google Privacy Policy, and use of YouTube itself is governed by the YouTube Terms of Service.

7. Changes to this policy

Any changes to this policy will be posted on this page, with the effective date updated accordingly.
